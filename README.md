# mark_reb

mark_reb


 ## Tecnologías usadas

- Flutter
- Dart 
- MySQL
- Firebase

## Apis

- `Maps SDK for Android` — Para funciones de geolocalización y mapas.
- `Remote Config`  — Permite cambiar variables en tiempo real sin necesidad de actualizar la app.
- `Firebase Cloude Messaging (FCM)` — Para el envío de notificaciones push.


## Instalación

1. Clona el repositorio
2. Ejecuta `flutter pub get`
3. Usa `flutter run` para lanzar la app


## Estructura

- `lib/`: Código principal.
- `lib/pages`: Pantallas.
- `lib/sevices`: Conexiones a la base de datos. 
- `lib/utils`: Funcionamiento del splash. 
- `lib/widget`: Doble Tap.
